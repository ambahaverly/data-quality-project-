# Synthetic Dataset Project

## Overview 
This project contains a small synthetic dataset for practicing Git version control.

## Dataset
The file 'Synthetic_data.csv' contains the following columns:

| Column | Description |
| -------|-------------|
| `record_id` | Unique Identifier for the record |
| `name` | Fictional Name associated with the record |
| `age` | Age of the fictional individual |
| `occupancy` | Job status of the individual |
| `country` | Country of residence for the individual

## Data Assumptions
- all records are synthetic and do not represent individuals factually
- each record_id is expected to be unique
- age is expected to be a numeric value
- country is expected to be a country name or recognisable region.
